Bundletool 1.18.3 reads each final bundle's manifest and resource table; the helper's
published copy must match that final artifact by SHA-256. `jarsigner` verifies all
12 bundles. `keytool` compares their certificate fingerprints with the generated
key for that phase. AAPT2 inspects each initial Release APK's identity, label and
API floors; `apksigner` verifies its signature and the same synthetic fingerprint.
Both APKs are non-debuggable Release products. Keys are generated independently
per phase, so cross-version certificate or whole-file equality is not asserted.
Raw compiled manifest/resource protobuf hashes are recorded without a binary
reproducibility claim. In both resource-revert stages, `base/resources.pb` differs
from its initial hash although the inspected string is restored. That byte
difference is retained and not attributed by this check. Native tests were
not run by this observation.

## Integration cost and remaining scope

The pinned [0.14.1 Android packaging guide](https://github.com/JetBrains/kotlin-toolchain/blob/f53674bce744f0b5e9ff235110dcc1d565d2c114/docs/src/user-guide/product-types/android-app.md#packaging)
documents `kotlin package -m android-app`, Release/R8/signing behavior and the final
`build/tasks/_android-app_bundleAndroid/gradle-project-release.aab` path. It calls
that layout temporary. This PR adds no build implementation, app workaround,
dependency override or private API adapter. The existing helper's explicit final
locator remains an update-review obligation: replace it when a supported artifact
reporting contract is qualified against the same signing/publication checks.
Do not restore manual Gradle cache-layout discovery.

Signing uses the repository's synthetic Android Debug key generator and
`CI_ANDROID_SIGNING_MODE=debug-smoke`, with local fixture version values.
Signing properties stay unchanged throughout each sequence. No production
credentials, upload or store lane is used. The check does not edit/requalify
signing configuration, ProGuard, assets or JNI inputs. Cold/relocated native
delivery, device execution, credentialed publication and the
[dependency findings](2026-11-21-toolchain-0141-dependencies.md),
[delegated-owner/observer gaps](2026-11-21-toolchain-0141-delegated.md) and
[warning backlog](../compiler-warning-follow-ups.md) remain separate work.
