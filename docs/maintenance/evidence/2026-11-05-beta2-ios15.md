# Beta2 development tuple and IOS-15 removal — 2026-11-05

This app change selects Kotlin 2.5.0-Beta2 and Metro 1.5.0 through Kotlin
Toolchain 0.13.0, and removes the test-only nested-state constructor workaround.
It updates the maintained Home/Nearby delivery and native tests. There is one
application path, one Kotlin archive and the same eight Debug Swift modules.

## Concrete improvement and cost

The existing Swift tests replace calls such as
`IosInteropTestStates.shared.riderAvailable(location:)` with
`RiderLocationState.Available(location:)`. The 43-line Kotlin helper and its
native-fixture runner registration are deleted. Existing state/equality,
failure/retry, cancellation, ordering and lifecycle assertions remain in place.
No generated source is patched and no mangled implementation name is consumed.

The compiler/API update is the supporting cost: nine module manifests explicitly
select Beta2, the three exporter coordinates match it, and Metro runtime/compiler
coordinates move together to 1.5.0. The existing exporter entry point, bridge
producer, module order and runtime packaging require no new integration code.
Two Swift cancellation-normalization call sites adopt Beta2's receiver-method
syntax (`state.cancelledRefreshState()`). No adapter is added; the shared behavior
and native presentation/reducer policies are unchanged. The first real app
compile exposed the old free-function calls before simulator tests could run.

The compatibility metadata explicitly marks the selected Kotlin release
`review_channel: experimental`. Only a reviewed tuple can make that selection;
release discovery cannot. The adapter records experimental selection, retains
the age gate and never authorizes adoption. A CLI age waiver alone cannot admit
an unmarked prerelease. The general release/adoption policy is unchanged.

Historical bridge declarations retain their old baseline. Current direct-source
Metro declarations are checked against the reviewed candidate, and direct
assessment records retired SKIE as unselected historical release metadata.
Transform-only contract fixtures use their historical Metro baseline and cannot
execute a native historical bridge on this source.
