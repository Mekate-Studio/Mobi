# AndroidX Lifecycle 2.11.0 stable qualification

Recorded 2026-11-07 against main `4ca0cdf1d36dacf407f1d00a892205263413660e`.
This is the effective version upgrade separated from PR #88's declaration-only
alignment. The implementation changes one Android dependency line from
`2.11.0-beta01` to `2.11.0`. Application source, tests and lifetime policy stay
unchanged. Final local/hosted results are recorded on the containing review PR.

## Official changes and actual usage

Reviewed the [official Beta02, RC01 and stable release entries](https://developer.android.com/jetpack/androidx/releases/lifecycle#2.11.0).
Beta02 fixes premature/recomposition-driven ViewModel clearing and duplication
with older JetBrains Lifecycle forks; stable retains the Compose UI 1.7+ floor.
The API 37 / AGP 9.2 requirement was introduced in Beta01, so this interval adds
no new requirement there. Mobi already declares compile SDK 37. The existing
Toolchain 0.13.0 / Kotlin 2.5.0-Beta2 / Compose 1.12.1 / Circuit 0.34.0 tuple stays.

Mobi's Home and Nearby presenters directly use `LifecycleStartEffect` for their
STARTED work ownership. `AppDestinationContent` uses Circuit's keyed retained
state providers. The [pinned Circuit registry](https://github.com/slackhq/circuit/blob/0.34.0/circuit-retained/src/sharedMain/kotlin/com/slack/circuit/retained/LifecycleRetainedStateRegistry.kt)
uses `LocalViewModelStoreOwner` and `viewModel`; its [retained holder](https://github.com/slackhq/circuit/blob/0.34.0/circuit-retained/src/commonMain/kotlin/com/slack/circuit/retained/RetainedStateHolder.kt)
is also part of that integration. Mobi does not directly call the newer scoped
ViewModelStoreProvider APIs. Their release-note fixes are upstream compatibility
context, not an attribution of a known Mobi bug or a new API adoption here.

## Required qualification and simplification boundary

Run the normal mandatory gate: Android/shared host tests, real iOS PullRequest
plan and both Debug builds. The existing tests cover Home/Nearby tab retention,
STARTED/STOPPED work cancellation, old callbacks, superseded locations, and late
success/failure. Keep their assertions and parameter matrices intact. Hosted CI
must qualify its final head as well as the supported local compiler tuple.
Host tests do not qualify process recreation, physical-device rendering or OS
location delivery. Existing interop limitations remain separately tracked.

The new ViewModel-owner APIs do not by themselves replace per-STARTED request
ownership. AND-01 / MOB-08 continue to track simplification on relevant
Circuit/Compose updates. This increment introduces no adapter, state field,
request registry or new interop workaround.
