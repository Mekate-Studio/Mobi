# Code of Conduct

`Mobi` is a public reference architecture repository. We want discussion,
critique, and collaboration here to be rigorous, respectful, and safe.

## Expected Behavior

Participants in this project are expected to:

- be respectful, specific, and constructive
- assume good intent while still giving honest technical feedback
- focus criticism on ideas, code, architecture, and decisions rather than
  people
- help keep discussion useful for readers, adopters, and contributors

## Unacceptable Behavior

The following behaviors are not acceptable in project spaces:

- harassment, intimidation, discrimination, or personal attacks
- trolling, baiting, or deliberately derailing discussion
- hostile, insulting, or demeaning language
- publishing private, sensitive, or identifying information without permission
- repeated low-signal or bad-faith participation after moderation requests

## Scope

This code of conduct applies to project spaces such as issues, pull requests,
discussions, and other public collaboration channels connected to `Mobi`.

## Enforcement

Project maintainers may remove, edit, lock, or reject comments, issues, pull
requests, discussions, and other contributions that are not aligned with this
code of conduct or with the purpose of the repository.

## Reporting

For non-sensitive conduct concerns in project spaces, raise the issue through
the normal project moderation channels when appropriate.

For urgent or sensitive concerns, use GitHub's platform reporting and abuse
reporting mechanisms. A dedicated private project reporting path may be added in
the future.
