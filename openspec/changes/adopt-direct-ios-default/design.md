## Risks / Trade-offs

- Inherited build-tool vulnerabilities → retain the bounded exception and original expiry; bridge transition is not remediation.
- Working documentation differs from candidate → preserve it, record deliberate merges and independently validate applied source.
- Existing hosted receipts used different source → require separate exact-revision hosted integration evidence; do not relabel those receipts.
- Direct Swift task cancellation remains limited → preserve measured current behavior and leave broader lifecycle claims open.
